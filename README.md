# AudioSpectrum for macOS

Macで再生している内部オーディオを、リアルタイムのスペクトラムとして表示するネイティブアプリです。通常のウインドウと、背景が透明なデスクトップオーバーレイを切り替えられます。ブラウザ拡張やカーネル拡張のインストールは不要です。

| 表示 | 動き |
| --- | --- |
| ① 円形 | 円周に沿ったバーが音に合わせて外側へ伸びます。 |
| ② バー・中央 | 横に並んだ縦棒が、中央の水平線から上下対称に伸びます。 |
| ③ バー・底 | 横に並んだ縦棒が、下端から上に伸びます。 |

周波数は低音から高音へ対数間隔で並びます。表示は音楽を楽しむための可視化であり、校正済みの測定器ではありません。

## 必要なもの

- macOS 14.2以降を搭載したMac。
- ソースからビルドする場合は **Xcode 15.2以降**と、macOS 14.2以降のSDK、Swift 5.9以降。
- 初回使用時の「システムオーディオ録音」の許可。

Xcode 15.2にはmacOS 14.2 SDKとSwift 5.9が含まれます。使用するXcode自体が、お使いのmacOSに対応している必要があります。[AppleのXcode 15.2リリースノート](https://developer.apple.com/documentation/xcode-release-notes/xcode-15_2-release-notes)

Core AudioのProcess Tapを使用します。BlackHoleなどの仮想オーディオドライバ、マイクの許可、画面の映像取得は使用しません。取得するのはMac全体で再生される音声です。[AppleのCore Audio Tapサンプル](https://developer.apple.com/documentation/coreaudio/capturing-system-audio-with-core-audio-taps)

## ビルドとインストール

1. Xcodeをインストールして一度起動し、初期設定を完了します。
2. このリポジトリをダウンロードし、ターミナルでそのフォルダを開きます。
3. 次のコマンドでアプリを作成します。

   ```sh
   ./scripts/build-app.sh
   ```

4. Finderでリポジトリ内の `dist` フォルダを開き、`AudioSpectrum.app` を「アプリケーション」へドラッグします。個人用の `~/Applications` でも使用できます。
5. コピー先の `AudioSpectrum.app` をダブルクリックします。権限を許可してからアプリの場所を変えず、同じコピーを起動して使用してください。

ビルドスクリプトは実行ファイル・Info.plist・アイコンをまとめ、ローカル実行用のアドホック署名を付けて検証します。生成先は常に `dist/AudioSpectrum.app` です。再実行すると、この生成物を置き換えます。外部ライブラリのダウンロードはありません。

現在選択中の開発ツールに問題がある場合は、Xcodeの場所を明示できます。

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer ./scripts/build-app.sh
```

デバッグ用アプリは次のコマンドで作成します。

```sh
./scripts/build-app.sh --debug
```

生成されるアプリはビルドしたMacのアーキテクチャ向けです。Apple SiliconとIntel Macの両方へ配布するためのUniversalアプリや、Developer ID署名・Appleの公証は、このスクリプトには含みません。手元でビルドしたアプリを開く際にmacOSの警告が出る場合は、[Appleの案内](https://support.apple.com/ja-jp/102445)に従ってください。

更新する場合は、メニューバーからAudioSpectrumを終了してビルドをやり直し、アプリケーション内のコピーを置き換えます。署名が変わるため、更新後にオーディオの許可を再確認する場合があります。

## 最初の使い方

1. AudioSpectrumを起動します。
2. 音楽プレーヤーやブラウザなどで音を再生します。
3. ウインドウの「開始」を押します（ショートカットは ⌘R）。
4. macOSがシステムオーディオへのアクセスを求めたら、許可します。macOSから再起動を求められた場合は、アプリを終了して再度開き、「開始」を押します。
5. 「円形」「バー・中央」「バー・底」から表示を選びます。
6. 終えるときは「停止」を押します。アプリ全体を終了する場合は、メニューバーのAudioSpectrumメニューから終了するか、⌘Qを押します。

初回のアクセス要求は、オーディオ取得を開始した時に発生します。音声はメモリ上で周波数解析するだけで、録音ファイルとして保存せず、外部へ送信しません。停止または終了すると取得を解除します。次回起動時の音声取得は停止状態です。

### 権限を後から変更する

「システム設定」→「プライバシーとセキュリティ」で、AudioSpectrumのシステムオーディオ録音を許可します。項目名はmacOSのバージョンにより「画面収録とシステムオーディオ録音」「システムオーディオ録音」などと表示されます。このアプリはオーディオだけを取得します。[Appleのアクセス設定の案内](https://support.apple.com/ja-jp/guide/mac-help/mchld6aa7d23/mac)

拒否した後や許可を変更した後は、AudioSpectrumを一度終了し、同じ場所にあるアプリを開き直してください。アプリでエラーが表示された場合は「音声収録の設定を開く」から設定を開けます。権限を取り消した後も表示が続く場合は停止して終了してください。

## ウインドウと透明オーバーレイ

「表示先」で「ウインドウ」または「デスクトップ」を選びます。「デスクトップ」では、スペクトラムを透明な背景でほかのウインドウの上に表示します。元のウインドウは設定用として残り、「デスクトップに表示中」と表示します。

- **移動・サイズ変更**: 「位置を固定・クリックを透過」をオフにし、オーバーレイ上部をドラッグして移動、右下のハンドルをドラッグしてサイズ変更します。
- **ロック**: 「位置を固定・クリックを透過」をオンにすると、クリックが背後のアプリに通るようになります。
- **設定に戻る**: 画面上部のメニューバーにある波形アイコンから、設定ウインドウを再表示できます。
- **操作できなくなった場合**: 波形アイコンのメニューから固定を解除するか、「ウインドウ」表示へ戻してください。メニューからオーバーレイの位置を初期化することもできます。ロック中でもメニューバーは操作できます。

ウインドウを閉じても、メニューバーから操作を続けられます。オーバーレイはスペクトラムを表示するためのもので、デスクトップの壁紙そのものを書き換える機能ではありません。次回起動時にはオーバーレイは無効になり、ウインドウ表示に戻ります。

### 表示設定

| 設定 | 用途 |
| --- | --- |
| カラー | ミント・ブルー・アンバーから配色を選びます。 |
| 感度 | 0.5〜3.0倍でバーの反応を調整します。Macの再生音量自体は変わりません。 |
| 不透明度 | デスクトップ表示時の濃さを20〜100%で調整します。 |

表示の種類・カラー・感度・不透明度は次回起動時にも引き継ぎます。

音量による動きを強く強調するため、小さい音ではバーが大きく縮み、大きい音では勢いよく伸びるように表示の差を広げています。大きな音でも高さが上限に張り付きにくい反応にしています。円形では円周から伸びる長さに反映されます。3種類とも、ウインドウ表示・デスクトップ表示で同じ反応になります。

## うまく動かないとき

### 音が再生されているのに反応しない

1. 「開始」を押し、取得が開始状態になっているか確認します。
2. 「プライバシーとセキュリティ」でAudioSpectrumへのシステムオーディオ録音の許可を確認し、アプリを再起動します。
3. 別のプレーヤーや、手元の音声ファイルで試します。著作権保護されたコンテンツやアプリ側の制限がある音声は取得できないことがあります。
4. Bluetoothイヤホン・USBオーディオ・HDMIなどへ出力先を変更した直後なら、「開始」を押して再取得します。出力先や音声形式が変わると、アプリは取得を停止して再開始を案内します。復帰しなければAudioSpectrumを再起動します。

マイクに向かって話しても反応しません。マイク音声をほかのアプリがMacの出力へ流している場合は、その出力に反応します。

### 許可したはずなのに取得できない

アプリケーション内と `dist` 内の別々のコピーを交互に起動していないか確認してください。使用するコピーを一つに揃え、macOSの設定でそのAudioSpectrumへの許可を確認します。再ビルド・移動・署名変更の後は、以前の許可が引き継がれない場合があります。

### オーバーレイが見つからない・クリックできない

メニューバーの波形アイコンから設定ウインドウを表示してください。ロック中のクリック透過は正常な動作です。固定を解除すると再度配置を調整できます。ディスプレイ構成を変えた場合は、メニューからオーバーレイの位置を初期化してください。

### ビルドできない

次のコマンドで、選択されているツールとSDKを確認できます。

```sh
xcode-select -p
xcrun swift --version
xcrun --sdk macosx --show-sdk-version
```

macOS SDKが14.2未満の場合や、Command Line Toolsのみで必要なSDKが見つからない場合は、対応するXcodeを選択してビルドしてください。ビルドスクリプトの出力に表示される最初のエラーを確認してください。

## 開発と確認

Swift Package Managerで構成し、SwiftUI / AppKit / Core Audio / Accelerateを使用します。

```sh
swift test
./scripts/build-app.sh
```

システムオーディオの権限を正しく扱うため、実際の使用には `swift run` の実行ファイルではなく、生成した `.app` を起動してください。

| 場所 | 内容 |
| --- | --- |
| `Sources/AudioSpectrum` | アプリUI、表示の描画、メニューバー、透明オーバーレイ、内部オーディオ取得。 |
| `Sources/SpectrumCore` | 周波数解析とスペクトラムのデータ処理。 |
| `Tests` | 周波数解析などの単体テスト。 |
| `Resources/Info.plist` | アプリ識別子、対応OS、システムオーディオの利用目的。 |
| `scripts/build-app.sh` | `.app` の組み立てとローカル署名。 |

単体テストだけでは権限ダイアログや実際のオーディオ取得を確認できません。実機では、初回許可・拒否後の再許可・3種類の表示・停止・オーバーレイのロックと復帰・出力先の変更も確認してください。

## アンインストール

1. メニューバーからAudioSpectrumを終了します。
2. 「アプリケーション」の `AudioSpectrum.app` をゴミ箱へ移動します。
3. 必要に応じて「プライバシーとセキュリティ」でオーディオ録音の許可を解除します。
4. 保存された設定も消したい場合は、終了後に次のコマンドを実行します。

   ```sh
   defaults delete dev.audiospectrum.mac
   ```

設定が未保存の場合、このコマンドは「ドメインが存在しない」というエラーを返します。仮想オーディオドライバや常駐ヘルパーの削除作業は不要です。
